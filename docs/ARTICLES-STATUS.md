# نظام المقالات الآلي: إيش جاهز وإيش لسه

> **الحالة: مكتمل في الكود، لكن لم يُشغَّل بعد.** يحتاج `npm install` + الاختبارات + مفتاح AI.

## ✅ جاهز ومختبر (35 اختبار: 17 للجودة والتشابه، 18 للنص الآمن، 19 للـ AI بمحاكاة)
| الجزء | الملف | بيعمل إيه |
|---|---|---|
| رابط عربي فيه الكلمات المطلوبة | `functions/_lib/articleText.ts` | `شقق للإيجار في مدينة نصر` ← `شقق-للايجار-في-مدينة-نصر` (بدون تشكيل، همزات موحّدة، أرقام لاتينية، ولو مكرر بيضيف -2) |
| عرض آمن للمقال | نفس الملف | عناوين، فقرات، قوائم، صور بـ alt وlazy، فيديو يوتيوب اختياري. **أي HTML أو رابط خطر (`javascript:`) بيتحوّل لنص عادي** (اختُبر بـ 6 هجمات في كل موضع) |
| فحص جودة السيو | `articleQuality.ts` | تقييم من 100 بملاحظات بالعربي: طول العنوان والوصف، الكلمة الأساسية في العنوان وأول 120 كلمة وعنوان فرعي، كثافتها (حشو)، عدد الكلمات والعناوين، روابط داخلية، FAQ، alt للصور، فقرات طويلة |
| كشف العبارات "المكتوبة آليًا" | نفس الملف | 26 عبارة جاهزة (في عالمنا اليوم، من الجدير بالذكر...) بتتمنع في التعليمات وبتتخصم في التقييم |
| منع تكرار المقالات | نفس الملف | بصمة MinHash لكل مقال: يكتشف المقال المشابه (حتى لو العنوان اتغيّر) بدون قراءة كل المقالات |

| حقائق حقيقية من موقعك | نفس الملف | عدد الوحدات وأسعارها ومناطقها من بيانات الموقع تتحط في المقال (بدل ما الـ AI يخترع) |

| مزوّدين للـ AI | نفس الملف | Gemini (فيه مستوى مجاني) أو Claude. مفتاح واحد يكفي، والمفتاح ما بيظهرش أبدًا |

## 🟡 مكتوب لكن **من غير اختبارات** ولا تشغيل (type-check نضيف بس)
| الجزء | الملف |
|---|---|
| تخزين المقالات + دليل واحد سريع + حفظ ذري بحماية من التعارض | `articleStore.ts` |
| التخطيط (عناوين متنوعة لنفس الموضوع) وكتابة مقال واحد وبوابة النشر التلقائي | `articleService.ts` |
| المجدول الآلي (مقال كل X ساعة، حد يومي، مراجعة أو نشر تلقائي، نشر مجدول، حماية من التشغيل المتداخل) | `articleService.ts` + `api/article-cron.ts` |
| نقاط الإدارة: حفظ/تعديل/نشر/جدولة/حذف/إعدادات، وتوليد (خطة + كتابة) | `api/articles-admin.ts`, `api/articles-generate.ts` |
| صفحات المدونة العامة (HTML كامل من السيرفر بدون JavaScript: سريعة جدًا) + بيانات منظمة (BlogPosting, FAQ, Breadcrumb, Video) | `_lib/articlePages.ts`, `blog/index.ts`, `blog/[slug].ts` |

## ✅ اتعمل في الجولة الأخيرة (مكتوب، type-check نضيف، **لسه ما اتشغلش عندك**)
- واجهة الأدمن `/admin/articles`: قائمة، توليد (موضوع، عدد، زوايا/تغيير بسيط)، محرر (صور، alt، يوتيوب، FAQ، معاينة، جدولة)، إعدادات الأتمتة وزر "شغّل الآن".
- تفعيل المدونة: `_routes.json`، الـ sitemap، `llms.txt`، CSP ليوتيوب، رابط في الهيدر والفوتر.
- `.github/workflows/articles.yml`، و`docs/ARTICLES.md` (الإعداد).
- اختبارات: `functions/_tests/blog-activation.test.ts` و`functions/_lib/articleService.test.ts` (التخزين، كتابة المقال بمحاكاة AI، بوابة النشر، المجدول والحد اليومي، النشر المجدول). **لازم تتشغّل عندك: `npm test`**، وممكن تحتاج تعديل بسيط لأني ما قدرتش أشغّلها.
- شريط "من المدونة" في الرئيسية (آخر 3 مقالات، من `/api/blog-latest`، لو فشل ما بيظهرش).

2. تجربة حقيقية بمفتاح AI، ومراجعة أول 5 مقالات بنفسك.

## ⚠️ ما اتأكدتش منه
- ما شغّلتش `npm install` ولا الاختبارات ولا الموقع (مفيش إنترنت عندي). فحصت الأنواع بمكتبات مبسّطة. شغّل `npm run test:all && npm run build` قبل الرفع.
- جودة الكتابة، وأسماء الموديلات، واقتراحات جوجل غير الرسمية: تحتاج تجربة.
