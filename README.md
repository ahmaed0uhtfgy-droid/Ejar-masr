# إيجار مصر — ejar-masr.pages.dev

منصة عربية (RTL) لعرض وحدات الإيجار في مصر. الستاك مجاني بالكامل: Vite + React + TS + Tailwind، Cloudflare Pages + Pages Functions، Firebase Spark (Auth + Firestore)، Cloudinary Free، Leaflet + OSM.

## تشغيل محلي
```bash
npm install
cp .env.example .env            # املا بيانات Firebase (Project settings > Your apps)
npm run dev
```
فحوصات: `npm run typecheck && npm run lint && npm test && npm run build`

## الإعداد (مرة واحدة)
1. **Firebase (Spark)**: فعّل Authentication (Email/Password + Google) وأنشئ Firestore. أضف `ejar-masr.pages.dev` في Authentication > Settings > Authorized domains.
2. **نشر القواعد والفهارس**: `firebase deploy --only firestore:rules,firestore:indexes` (الملفين `firestore.rules` و`firestore.indexes.json`). الفهارس بتتولّد بـ `npm run gen:data`.
3. **أول أدمن**: سجّل حساب من الموقع، وبعدها من Firebase console > Firestore > `users/{uid}` غيّر `role` إلى `admin`.
4. **Cloudinary (Free)**: خد `cloud name` و`API key` و`API secret`. مفيش unsigned preset — الرفع بتوقيع من `/api/sign-upload`.
5. **Cloudflare Pages**: اربط الريبو. Build command `npm run build`، output `dist`، ومتغيّرات البناء `VITE_FIREBASE_*` و`VITE_SITE_URL`.
   أسرار الـ Functions (Settings > Variables and Secrets، كـ Secret): `FIREBASE_PROJECT_ID`، `FIREBASE_SERVICE_ACCOUNT` (JSON كامل لـ service account من Firebase)، `CLOUDINARY_CLOUD_NAME`، `CLOUDINARY_API_KEY`، `CLOUDINARY_API_SECRET`، و`SITE_URL`. ماتحطش أي منهم في الكود.
6. `.github/workflows/ci.yml` ملف جديد — الصقه يدويًا.

## الحصص (Firestore Spark)
المصدر الرسمي (firebase.google.com/docs/projects/billing/firebase-pricing-plans): **50,000 قراءة و20,000 كتابة يوميًا**. (حد الحذف 20K ومساحة 1 GiB من مصادر ثانوية — راجعهم في صفحة Firestore quotas.) لما الحصة تخلص العمليات بتترفض والموقع بيعرض رسالة "وصل لحد الاستخدام اليومي".

تقدير التكلفة (من الكود، مش قياس فعلي):
| العملية | قراءات | كتابات |
|---|---|---|
| فتح الموقع (إعدادات + مواقع، كاش جلسة ١٠ دقايق) | 2 | 0 |
| صفحة بحث (حتى ٣ جولات × ٢٤) | ≤ 72 | 0 |
| كشف تواصل جديد | ~6 | 3 |
| مشاهدة (مرة/IP/وحدة/٦ ساعات) | 1 | 1 |
| sitemap (كاش ٦ ساعات) | ≤ 501 | 0 |
**أكبر مخاطرة:** المشاهدات المجهولة بتاكل من حصة الكتابة (٢٠ ألف/يوم). عطّلها من الإعدادات (`تتبع المشاهدات`) لو زادت.

## قرارات صممتها (غيّرها لو عايز)
- **بعد انتهاء مدة الإعلان**: بيتخفى من البحث والصفحات الهبوط، وصفحته بتعرض "لم يعد متاحًا" للزوار (للمعلن والأدمن بتظهر "انتهت المدة")، والكشف بيتمنع (410). الحالة في قاعدة البيانات بتفضل `active` — مفيش cron. الأدمن بيمدد من لوحة الإعلانات.
- تغيير المدة الافتراضية بيسأل لو تطبّقها على الإعلانات الحالية اللي على "الافتراضي" (لحد ٢٠٠ إعلان في المرة) وبيبعت إشعار لكل معلن.
- الأدمن "حذف" إعلان = `status: removed` (soft delete). المعلن "حذف" = حذف فعلي.
- بدل `_redirects` للـ SPA: Pages بتعمل fallback تلقائي لـ `index.html`، و`public/_routes.json` بيحدد الـ Functions على `/api/*` و`/unit/*` و`/rent/*` و`/sitemap.xml` بس.

## حل المشاكل الشائعة
- **403 permission-denied على `units`**: القواعد مش منشورة. نفّذ `firebase use ejar-masr-5301c && firebase deploy --only firestore:rules,firestore:indexes`.
- **"انتهت الجلسة" أو 401 عند رفع الصور**: افتح `https://ejar-masr.pages.dev/api/health`. كل القيم لازم `true` و`serviceAccount: "ok"` و`projectMatches: true`. لو لأ، صلّح المتغيرات في Cloudflare (Production) وأعد النشر (Redeploy).
- **400 على signInWithPassword**: بريد/كلمة سر غلط، أو Email/Password مش مفعّل في Firebase Authentication.
- تحذير `Cross-Origin-Opener-Policy` مع تسجيل الدخول بجوجل: عادي ومبيأثرش.

## الإيجار والدفع الشهري مع حجز الفلوس (Paymob)
**الدورة:** المستأجر يبعت طلب إيجار ← المالك يقبل ويحدد قبل كل قسط بكام يوم يتذكّر المستأجر ← الوحدة تختفي من العرض لحد نهاية مدة العقد ← المستأجر يدفع (القسط الأول + التأمين لو فيه) أونلاين ← **الفلوس بتتحجز في حساب الموقع (escrow)** ← من تاريخ بداية العقد المستأجر بيتسأل يوميًا "استلمت الوحدة؟" ← لما يأكد، الفلوس تتحرر وتظهر للأدمن "في انتظار التحويل" ← الأدمن يحوّل للمالك ويسجّل التحويل. لو المستأجر ماأكدش، الفلوس **مبتتحولش** (والأدمن يقدر يحررها يدويًا في حالة نزاع).

**الأدمن (صفحة المدفوعات `/admin/payments`):** إعدادات (تشغيل/إيقاف الدفع، العمولة، أقصى مدة عقد، دورات الدفع المسموحة، التذكير الافتراضي، مهلة مطالبة التأمين، أقصى طلبات للمستأجر، مدة تذكير تأكيد الاستلام) — تحويلات الملّاك — الفلوس المحجوزة (وبلاغات عدم الاستلام) — التأمينات (مطالبات وتسويات) — كل العقود (وإنهاء إداري) — تشغيل الفحص اليومي يدويًا.
الإعدادات بتتحفظ في `settings/payments` (منفصلة عن `settings/app`). العمولة بتتحسب على الإيجار فقط (مش التأمين) وبتتثبّت على كل عقد وقت الطلب.

**لوحة المالك (`/dashboard`):** ملخص (وحدات معروضة/مؤجرة/مخفية، طلبات جديدة، عقود شغالة، المحجوز، المستني تحويل، اللي اتحوّل، التأمينات المحجوزة، أقرب قسط، رسم بياني شهري) + الطلبات والعقود + أي وحدة مؤجرة بتظهر "مؤجرة حتى ..." ومبتتفتحش ولا بتتحذف قبل النهاية (القواعد بتمنع ده).

**التأمين:** المالك يختار لكل وحدة من فورم الإعلان: بدون تأمين في الموقع / محجوز ويرجع آخر العقد إلا لو قدّم مطالبة والأدمن يحكم / محجوز ويرجع كامل بدون مطالبات. بيتدفع مع القسط الأول ويتحجز، والأدمن يسوّيه من تبويب التأمينات.

**التذكيرات (داخل الموقع + إيميل):** قبل القسط بعدد الأيام اللي حدده المالك، وقبله بيوم، ويوم الاستحقاق، وكل ٣ أيام بعد التأخير (لحد ١٣ يوم). وتذكير يومي بتأكيد الاستلام. كمان المستأجر شايف عدّاد "باقي كذا يوم" في **إيجاراتي**.

**الفحص اليومي `/api/sweep`:** بينهي العقود اللي مدتها خلصت ويرجّع وحداتها للعرض ويبعت التذكيرات. بيشتغل من GitHub Actions (`.github/workflows/sweep.yml`، الصقه يدويًا لو الـ PAT مبيسمحش بـ workflows) ويقدر الأدمن يشغّله من الصفحة. الحد في الخطة المجانية ~٥٠ طلب خارجي للتشغيلة، فالفحص بيقف عند حد ويرجّع `more:true` والـ workflow بيكرر لحد ما يخلص.

**الإعداد:**
1. Paymob (Accept): `Secret key`، `Public key`، `HMAC secret`، `Integration ID`، وخلّي **Transaction processed callback** = `https://<موقعك>/api/pay-webhook`.
2. Cloudflare Pages → Secrets: `PAYMOB_SECRET_KEY`، `PAYMOB_PUBLIC_KEY`، `PAYMOB_HMAC_SECRET`، `PAYMOB_INTEGRATION_IDS` (مفصولة بفاصلة)، `CRON_SECRET` (أي نص عشوائي طويل)، وتأكد من `SITE_URL`.
3. الإيميل: حساب Resend (مجاني ١٠٠ إيميل/يوم) + دومين متحقق منه ← `RESEND_API_KEY` و`EMAIL_FROM` (مثال: `إيجار مصر <noreply@your-domain.com>`). من غيره التذكيرات بتوصل جوه الموقع بس.
4. GitHub → Settings → Secrets: `SITE_URL` و`CRON_SECRET` (نفس القيمة).
5. `firebase deploy --only firestore:rules`، وبعدها افتح `/api/health` وتأكد من المتغيرات.
6. ادخل `/admin/payments` واضبط العمولة والإعدادات.

**ملاحظات أمان:** المبلغ بيتحدد من Firestore فقط، والدفع بيتأكد بالـ HMAC ومطابقة المبلغ والعملة، و`leases` و`payments` للقراءة فقط من العميل، والأدمن يقدر يغيّر حالة التحويل بس.

**لازم تنتبه له:**
- **ماجرّبتش الكود على Paymob حقيقي** (مفيش إنترنت في بيئة التطوير) ولا شغّلت `tsc`/الاختبارات الكاملة. جرّب بمفاتيح Test وراجع شكل الـ callback.
- الفلوس بتدخل حساب Paymob بتاعك، والتحويل للمالك ورد التأمين للمستأجر **يدوي** (الأدمن يحوّل برّه الموقع ويسجّل). وأي استرداد من Paymob بيتم من لوحتهم. الاحتفاظ بفلوس ناس تانية وتحويلها ممكن يحتاج ترخيص أو خدمة Split/Payouts، فاستشر مختص قانوني قبل الإطلاق.
- لو العقد خلص والمستأجر ماأكدش الاستلام، الفلوس بتفضل محجوزة لحد قرار الأدمن.

## سياسة الإيجار والدفع
صفحة `/payments-policy`. النص الافتراضي في `src/i18n/policy.ts`، ولما الأدمن يحفظ تعديل من **المدفوعات ← السياسة** بيتخزّن في `settings/policyPage`. الأدمن يقدر: يعدّل الأقسام والنقاط (إضافة/حذف/ترتيب)، يخفي الصفحة بالكامل (بتختفي من الفوتر وتدّي 404 وموافقة المستأجر عليها بتبطل تكون مطلوبة)، ويشغّل/يقفل تنويه "قيد المراجعة". علامات زي `{fee}` و`{payoutDays}` جوه النص بتتبدّل أوتوماتيك بقيم إعدادات الدفع. المستأجر بيوافق على السياسة (checkbox) قبل الطلب، والسيرفر بيسجّل نسختها ووقت الموافقة. النص مسودة ومش بديل عن مراجعة محامٍ.

**قرارات المنتج المطبّقة:** الفلوس مبتتحولش للمالك إلا بتأكيد المستأجر (حتى الأدمن مش قادر يحررها، والقواعد بتمنع ده؛ بيقدر يسجّل رد للمستأجر بس). العمولة على كل دفعة، والأدمن يحدد مين بيتحملها (المالك/المستأجر/مناصفة) والنسبة. الرد كامل لو المستأجر ماستلمش. الإلغاء بعد الدفع وقبل الاستلام: الأدمن يختار ممنوع أو "طلب إلغاء" برسوم يحددها. أول تحويل لمالك جديد فوق حد معين بيظهر عليه تنبيه مراجعة هوية. أيام التحويل والرد والنزاع قابلة للتعديل. التحويل للمالك لسه يدوي لحد ما تتفعّل بوابة بتدعم التوزيع التلقائي.

**قرارات إضافية مطبّقة:** (١) مفيش دفع قبل ما المالك والمستأجر الاتنين يأكدوا من "إيجاراتي" إن العقد اتوقّع فعليًا والوحدة اتعاينت (السيرفر بيرفض الدفع قبل كده). (٢) نزاع التأمين بين الطرفين: المالك يقدّم مطالبة ← المستأجر يوافق (تتحول) أو يرفض (الفلوس تتجمّد) ← المالك يقدر يسحبها فيرجع التأمين كامل للمستأجر. الأدمن بينفّذ بس: رد كامل بعد انتهاء المهلة من غير مطالبة، أو تسوية نزاع بأساس مكتوب (اتفاق أو حكم قضائي).
